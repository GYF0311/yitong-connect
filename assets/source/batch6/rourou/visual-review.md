# 肉肉单张视觉核验

使用内置 image_gen：先生成设定图，再以设定图为参考独立生成10个姿势。原始生成文件保留在本目录，generation-log.json记录逐张提示词与原始输出路径。

- 已逐张通过拼板检查：圆脸、短嘴边毛、长耳毛、水蓝色领结和金铃铛延续；无人物照片、文字、logo。think按任务要求含问号符号。
- 坐姿和站姿均完整，透明背景真实alpha，不是棋盘背景。所有单张主体按alpha>8边界缩放到700px以内，脚底y=868–869（包围盒exclusive bottom=869–870，偏差1px）。
- sleep为趴姿，think包围盒含问号气泡，因此轮廓高度不能直接比较身体比例；拼板中think狗头略小，可作为后续一致性复审优先项。
- 设定图背面出现颈后领结/铃铛，该项不作为正面资产的配饰位置依据；正面姿势固定颈前。
- 这些是已生成并经技术与视觉检查的候选素材，尚无人工approved。
- 动画由其他线程负责，本线程未改动画。
