# 小桐 idle / wave 制作与检查

- 使用内置 image_gen，先参考 sheet 生成真实待机基准，后续逐帧参考该基准进行编辑。原生生成尺寸 1254×1254，未伪称原生 1024。
- 交付 idle 8 个播放槽位（6 个独立画面）；wave 8 个播放槽位（7 个独立画面）。所有交付均 1024×1024 RGBA，alpha extrema 0–255，头顶 y=90，脚底 y=940（bbox bottom-exclusive 941）。原生图、导出映射和代码保留在本目录。
- 端点复用：idle/01 与 idle/08 同一真实生成待机帧，确保8→1像素完全一致；wave/01 与 wave/08 复用同一待机端点，保证返回idle。idle/04 与 idle/06 复用同一真实半闭眼帧，形成闭眼前后对称过渡；idle/05 为全闭眼帧。其余姿势均真实逐图生成。
- 剔除：最初 idle/04 张嘴，重绘修嘴后丢失蓝丝带，两个版本均留在 rejected 文件中；最初 wave/01 误生成抬手，已替换为正确待机端点。没有把这些不符帧交付。
- 肉眼查看 contact-final.png：人物身份、衣服类别、扣子数、发夹侧别一致。idle/07 肩部、脸的相对位置及裙褶变化在本组最明显；wave/03、wave/06 的肩线/发梢相对静止帧存在轻微重绘漂移，不能声称像素锁定。
- bbox 宽度：idle 388–395px（发丝、裙摆轻动），wave 380–389px（动作造成肩胯及裙褶轻微差异）。脚底偏差0px，中心横坐标偏差不超过1px。未因表情差异进行非均匀形变。
- 10fps 预览：source/batch6/preview/xiaotong-idle.gif、xiaotong-wave.gif。idle 循环端点一致；wave 有抬手、左右摆手、收手，约0.8秒，8槽位属于离散关键帧，尚有轻微身体重绘感，不能等同真实骨骼动画。
- 白底及深蓝底边缘复核：edge-white.png、edge-deepblue.png。肉眼未见明显整圈白/灰/红边；idle/08 有10个高饱和红散点（alpha>16），记录为少量边缘散点残留，不声称零瑕疵。

## 提示词要点

统一约束：同设定图动画电影风格3D、同脸长黑微卷发、藏青罗纹短袖白花领白翻边袖口珍珠扣、藏青小腿百褶裙、白玛丽珍鞋、画面右蓝发夹金铃铛蓝丝带。1024透明，头顶90脚底940，仅改动作无文字无logo无残影。

idle：01/08自然站立双手轻搭；02轻吸气；03吸气高点和发梢右飘；04/06半闭眼；05闭眼；07睁眼恢复。wave：01自然站；02抬手；03手到脸旁掌心镜头；04手腕向右；05手腕向左；06手腕向右；07放手到胸口；08回idle。
